TASKFLOW — STAGE 4: WORKING KANBAN BOARD

Extract into ~/Projects/taskflow (existing Next.js project).

Files:
  app/board/page.tsx
  components/taskflow/workspace-shell.tsx

Install:
  cd ~/Projects/taskflow
  unzip -o ~/Downloads/taskflow_kanban_stage4.zip -d .
  npm run dev

Open: http://localhost:3000/board

Use your existing account. The board shares the SAME public.tasks table and user_id RLS rules with Dashboard.
- Drag cards between columns on desktop.
- Change status via the "Move to" selector on phones or with keyboard.
- Create, edit, delete, search, and filter tasks.
- Click "Kanban Board" in the existing Dashboard sidebar to navigate.

Before publishing, run npm run build and test:
1. Create a task on /board.
2. Change status; reload /board to confirm the status persisted.
3. Open /dashboard; confirm the same task and status are visible.
4. Verify mobile layout and Login after reloading.

No SQL changes or new environment variables required.
Do not push if a build or behavior test fails.
